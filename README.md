In 2019, during the second year of my Bachelor degree in Mathematics, I participated in a programming competition in which students were required to develop a program using Python skills. The focus of the challenge was not on advanced algorithms or complex theoretical concepts, but rather on applying practical programming techniques effectively.

The objective was to implement a game-playing program capable of competing against other participants’ solutions. The selected game was Connect Four, a classic strategy game in which each decision can significantly affect the outcome. Although the implementation does not rely on sophisticated ai or advanced strategic modeling, the project represents an important milestone in my development as a programmer.

I am particularly proud of this work as it was my first substantial programming challenge and resulted in a second-place finish in the competition. While the program is relatively simple and can likely be outperformed by more advanced approaches, it remains a meaningful project to me and serves as an early example of my applied programming experience.
